# NoteLine Package 3 (.nlchart)

当前 `.nlchart` 是包含音乐的单文件二进制包，音频与封面保存原始字节，不使用 Base64、不转码。原六首曲目已独立保存至 exports，不再随游戏曲库自动加载。

文件顺序：8 字节 ASCII `NLCHART2` → 4 字节小端无符号整数（元数据长度）→ UTF-8 JSON 元数据 → 原始音频字节 → 可选封面字节。

元数据为 `{format:"noteline.package", revision:3, title:"My Stage", charts:{easy?:<NoteLine Score 1 或 2>, normal?:<NoteLine Score 1 或 2>, hard?:<NoteLine Score 1 或 2>}, assets:{audio:{bytes,mime}, cover:{bytes,mime}|null}}`。音频必须存在；资源长度需要与整个文件严格一致，截断、尾随数据及超限长度会被拒绝。谱面元数据最多 8MB，音频最多 100MB，封面最多 5MB（PNG / JPG / WebP）。

导入新谱面包只需选择一个文件，同时载入谱面、音频与封面。旧 JSON / Score 1 文件保留导入兼容，只有这种没有内嵌音频的旧文件需要补选音乐。

## 内部 NoteLine Score 1

NoteLine 自有谱面格式。内部谱面元数据是 UTF-8 JSON，按四轨分组，用整数微秒表达音频绝对时间；没有原作的 `var songData`、轨道对象索引、`start: "end"` 或 3 秒倒数偏移。计时不依赖帧数，也不依赖四舍五入后的 BPM 网格。

```json
{
  "format": "noteline.score",
  "revision": 1,
  "meta": { "title": "My Stage" },
  "audio": { "durationUs": 10000000 },
  "timing": { "bpm": 137.125, "originUs": 375123 },
  "tracks": [
    { "key": 0, "events": [ { "atUs": 500123, "kind": "tap" } ] },
    { "key": 1, "events": [] },
    { "key": 2, "events": [ { "atUs": 1000001, "kind": "hold", "lengthUs": 1250986 } ] },
    { "key": 3, "events": [] }
  ]
}
```

- `revision`：协议版本，支持 1 和 2；仅含单击/长按时导出 1，含路径音符时导出 2；未知版本拒绝载入。
- `audio.durationUs`：音乐时长，正整数微秒；音符不能越界。
- `timing.bpm`：20–400，可为小数。该版本是一段固定 BPM；不是变速谱面格式。
- `timing.originUs`：第一拍相对音频零点的位置，可为负值。与设备判定补偿、倒数和下落预备时间独立。
- `tracks`：恰好四轨，唯一的 `key` 0–3 对应 D / F / J / K。
- `events[].atUs`：相对音频零点的非负整数微秒。
- `kind`：`tap` 或 `hold`。长按必须提供 `lengthUs`，至少 80000µs；单击不允许持续时间。
- 同轨音符不能重复、重叠；一首谱面最多 50000 音符，时长最多一小时。

编辑器数字属性允许输入 0.001ms，写入文件时换算为整数微秒。网格保持浮点计算，最终只量化到微秒；修改首拍与 BPM 不重写既有音符时间。存储精度不代表设备输入或音频输出也具有微秒级物理精度。

原六首曲目的独立文件为 `.nlchart`；浏览器旧自制曲目读取时迁移为 NoteLine Score，音频保留。旧 JSON 与原作包装可导入转换；编辑器导出统一产生带音频的 Package 3。同一首歌可包含简单、普通、困难中的任意非空组合；没有谱面的难度不会在选曲菜单显示。Package 2 旧文件会把其唯一谱面载入普通难度。


## Score 2：流星与弹跳路径

Score 2 保留 Score 1 的时间、轨道和音频定义，增加 `meteor`（流星）与 `bounce`（弹跳）。事件仍放在起始轨道的 `events` 中，`atUs` 为头部时间，`nodes` 为之后依次到达的轨道与绝对音频时间，不包含头部本身：

```json
{"atUs":1000000,"kind":"meteor","nodes":[{"key":1,"atUs":2000000},{"key":2,"atUs":3000000}]}
```

把 `kind` 改为 `bounce` 即为弹跳路径。节点 1–256 个，相邻节点（包括头部到首节点）间隔至少 160000µs，轨道 0–3，时间严格递增且不超出音乐。路径音符不使用 `lengthUs`，结束时间取最后节点。整张谱面含路径节点最多 50000 个。

- 流星头部沿用单击窗口；之后保持在当前轨道中心，到下个节点前才平滑变轨（最长 240ms，且不超过节点间隔的 35%），节点时间表示到达新轨道的时间；玩家按住当前最近轨道，跨轨可重叠按键或滑动触摸。触摸跨轨会连续转移按住状态，不触发额外点击或 Early。连续离开所需轨道超过 220ms 记 Miss，尾部允许提前 90ms 松开。流星头部和每个路径节点分别计入 Combo 与分数，同一节点只结算一次；头部播放击打音，尾部不播放。中途失败保留已完成节点，剩余节点计为 Miss。
- 弹跳头部先以正常下落速度沿起始轨道滑落，拥有完整下落预备时间；到首个判定点后才开始沿路径弹跳。每个落点（含头部）独立采用单击窗口、独立计分和播放音效。漏掉或 Early 消耗一个落点，不会删除后续路径。空按保持无惩罚；持续按住不会自动打中后续落点。
- 冲突检查按流星实际经过的轨道时段、弹跳各落点判定时间执行，不占用整条路径的起始轨道。
- 编辑器 M / B 创建流星 / 弹跳，拖动创建初始路径；V 选择后可拖动节点，或在右侧增删节点、输入精确时间并应用。移动整个音符同时移动全部节点，支持撤销、重做和实时预览。

运行时归一化表示使用毫秒：`{kind,lane,time,end,path:[{lane,time},…]}`，其中 `end` 等于最后节点时间。谱面包仍为 Package 3，原音频和封面字节保持不变。
