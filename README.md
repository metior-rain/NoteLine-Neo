# NoteLine

基于 [metior-rain/NoteLine](https://github.com/metior-rain/NoteLine) 重写的四轨音游。欢迎页、全屏选曲菜单和游戏在同一路径内切换，选曲后自动进入倒计时。卡通舞台配橙、蓝、紫、绿四轨，界面以蓝色为主并搭配多种颜色；谱面编辑器独立运行。已有封面保留原色，无封面歌曲使用灰色占位图。

## 启动

Node.js 20+。游戏使用 PixiJS 8 / WebGL 渲染，编辑器独立运行。

```sh
npm install
npm run dev
```

游戏：http://localhost:5173/ 。编辑器：http://localhost:5173/editor.html 。不要双击 HTML；曲库和波形需要通过 HTTP 读取。自定义端口：`PORT=8080 npm run dev`。

## 游戏

D / F / J / K 对应四条轨道。手机可以直接按住相应轨道，支持多点触控。空格开始 / 暂停；Esc 暂停，暂停时再按 Esc 恢复。开始时先进行 3 秒倒数，期间没有音符下落；结束后开启第一音符的下落预备，随后从音频零点播放音乐。首次音符有完整下落路程，音乐开头不会被裁剪。每次恢复有 3 秒倒数。恢复期间音乐与判定时钟保持静止；若暂停前存在未结束的长按，需要在恢复倒数期间重新按住对应轨道。切换窗口自动暂停。

曲名按钮打开全屏封面卡片画廊，可搜索、收藏、选择原谱 / 简化 / 演示，或直接导入包含音频的 .nlchart 谱面包。设置支持音量、下落速度、判定偏移、击打音效。1× 下落速度固定为每秒 600 CSS 像素，窗口高度只改变可见轨道长度；长按长度和音符间距不随窗口高度缩放。首次下落预备时间按轨道实际长度计算。内置五首原作曲目，以及基于 Boring 原时间点制作的长按练习版（61 单击 + 30 长按）。原作谱面未经节拍量化；BPM 在编辑器中用于参考网格，可自行调整。

### 打击反馈

命中触发闪光、扩散双环、方向光片、轨道脉冲、判定弹出与轻微回弹。长按持续显示流光和旋转蓄力环，完成尾部释放更密集的粒子。每 10 连击产生四轨波纹。击打音由短促的高频起音与下滑音层组成，可关闭。音频时钟与视觉动画独立；不使用会拖慢判定的停帧。系统开启减少动态效果时关闭镜头位移并减少粒子。按钮悬停、按压释放、浮层开关、倒数与连击采用阻尼弹簧曲线；开关可中途反向衔接。减少动态效果时跳过 UI 弹簧。

### 判定

Perfect ±45ms、Great ±90ms、Good ±140ms。漏过头部判定窗口记 Miss。

**提前 140–220ms 击打显示 Early 并断连**；更早的按键为空按，不影响连击、分数或准确率，也不消耗未来音符。失败单击先变灰，再在 380ms 内淡出；失败长按保持灰色并继续下落，直到尾部经过判定线。失败音符不能再次得分。键盘自动重复和仍按住同一轨道时的重复输入不产生额外判定。

长按头部命中后进入持续状态，持续到尾部才结算一个完整音符。早于尾部 90ms 以上松开记 Miss；在允许的尾部窗口松开，取头部与尾部中较弱的等级。持续按到尾部自动完成；尾部之后松开不重复计分。长按不额外刷连击，同一轨道不允许重叠音符。

满分 1,000,000。Perfect / Great / Good / Miss 权重为 1 / 0.75 / 0.4 / 0。分数 = 已获得权重 / 总音符数 × 1,000,000；准确率 = 已获得权重 / 已判定音符数。音乐结束补记未完成音符。自动演示不保存成绩；普通成绩与设置、收藏保留在当前浏览器。

## 独立编辑器

- 打开内置曲目、自己的音频或 包含音频的 .nlchart 谱面包；旧 JSON 可导入转换。
- 显示真实音频波形、四轨时间轴、播放光标和小节网格。
- **V** 选择工具；拖动移动音符，Shift 点选或框选多个音符；拖动长按尾部调整时长。
- **T** 单击工具；点击放置单击音符。
- **H** 长按工具；在轨道上拖动绘制长按。
- **首拍 / ms** 设置节拍网格起点，支持负值；也可点击波形定位，再按「光标设为首拍」。首拍只改变网格与吸附，不移动已有音符；支持撤销 / 重做并随谱面保存、导出。
- **Alt** 拖动时临时关闭吸附；可选 1/4、1/8、1/16、1/32 网格或关闭吸附。
- 右侧属性面板可以修改轨道、音符类型、开始和结束毫秒数。
- **Delete** 删除；**Ctrl / ⌘ Z** 撤销，**Ctrl / ⌘ Shift Z** 重做；箭头键移动已选音符。
- **实时预览** 使用与游戏相同的 PixiJS 渲染器，跟随音乐与光标，并立即反映放置、移动、长按、撤销与首拍调整。
- **Space** 播放 / 暂停。点击标尺或波形定位音乐；支持缩放、水平滚动及播放时自动跟随。
- 同轨重复、重叠、越过音乐结尾的修改会被拒绝并回滚。
- 导出包含谱面、原始音频与封面的单个 .nlchart 文件，或「保存到曲库」存入 IndexedDB；「试玩」打开独立游戏页并选中保存的谱面。
- 原作内置谱面作为模板，保存为新的自制曲目；重新打开已导入的曲目会更新该自制曲目。替换未保存内容前有确认提示。

文件和音乐只保存在本机浏览器，不上传。清除浏览器存储会移除导入音乐、成绩和设置。localhost 与 127.0.0.1 的曲库独立。

曲库将音频与封面保存为独立字节，读取时重新创建资源，避免 Safari 保存文件切片后读回错误内容。旧记录会自动迁移；若旧资源仍包含完整 `.nlchart` 文件，则自动提取并修复音频与封面，保留编辑过的谱面。无法恢复的记录会提示重新导入，不会自动删除。

## 谱面格式

对外导出使用自有的 **NoteLine Package 3 / .nlchart**，在一个二进制文件内保存谱面、原始音频和可选封面。内部谱面数据为 NoteLine Score 1 / 2，按四轨分组、显式音符类型、整数微秒时间和独立首拍起点。详细协议见 [docs/score-format.md](docs/score-format.md)。内置谱面和旧本地曲库会转换；原作 JSON 仅作为导入兼容。

## 验证与结构

```sh
npm test
npm run check
```

`src/game-renderer.js` 是 PixiJS 场景与复用精灵；`src/impact.js` 管理有限生命周期的打击粒子、回弹和长按流光；`src/engine.js` 独立判定模块；`src/app.js` 游戏；`src/editor.js` 编辑器交互；`src/editor-model.js` 编辑事务与撤销；`src/shared.js` 曲库和存储。`npm run dev` / `npm start` 自动构建游戏渲染模块；修改渲染源码后执行 `npm run build` 并刷新。静态托管前执行 `npm run build`，保留 `runtime/` 目录与许可证文件。`server.mjs` 仅用于本地预览。

验证范围见 [docs/verification.md](docs/verification.md)，原作素材来源见 [NOTICE.md](NOTICE.md)。

编辑器的「封面」按钮支持 PNG / JPG / WebP（最多 5MB），可预览、更换或移除。封面与音频一起保存到本地曲库，选曲画廊同步显示；`.nlchart` 导出同时包含音频和封面。

自定义与导入歌曲可在菜单卡片右上角删除；已删除歌曲保留在回收站，刷新后仍可恢复。内置歌曲不提供删除按钮。

游玩页右上角为暂停按钮，设置及编辑器入口仅出现在菜单。按钮使用白灰立体表面和彩色图标，多彩舞台背景保留。

编辑器新增快捷键：F 跟随、Home 回到开头、[ / ] 光标前后移动一拍、Ctrl / ⌘ A 全选、Ctrl / ⌘ S 保存、Ctrl / ⌘ Shift S 导出、Ctrl / ⌘ O 打开。点击键盘图标或按 ? 查看完整说明。

默认曲库为空，通过菜单导入 `.nlchart` 添加曲目。原六首曲目已独立打包在 `exports/NoteLine-谱面包.zip`，每个文件包含音乐、封面和普通难度谱面。编辑器从空白项目开始，使用打开音频或打开谱面包载入。


### 流星与弹跳音符

- **流星**：圆润四角星头部和渐变路径，平时保持在轨道上，接近变轨节点时短暂平滑换轨，支持键盘与触摸滑轨；换轨有 220ms 容错，头部与每个路径节点独立计分、增加连击。
- **弹跳**：沿判定线的弧线弹跳，每个落点分别点击和判定，提前显示下一落点；一次漏击不移除后续落点。
- 编辑器新增 **M / B** 工具，拖动创建路径，选择后拖动节点或在属性区编辑/增删节点。多难度、撤销、预览及带音频导出均支持。
- 含新音符的文件使用 Score 2，旧文件继续兼容，详见 [谱面协议](docs/score-format.md)。[动态视觉预览](http://localhost:5173/tests/path-preview.html) 不会修改曲库。
