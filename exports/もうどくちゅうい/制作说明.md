# もうどくちゅうい · NoteLine 三难度谱面

歌曲：でんの子P / 蒼姫ラピス。谱面包内嵌用户提供的原始 MP3，以及其原有 JPEG 封面。

节拍网格 140 BPM，起点 0ms；音乐完整解码时长 169201.134ms。网格起点由跨段落低频击打与局部波形核对，未直接采用八分拍相位。开头保留弱起：简单首音 428.571ms，普通/困难首音 321.429ms。游戏倒计时与预滚动由引擎负责，未写入音符时间。结尾保留原音频衰减与静音，不裁剪音频。

|---|---:|---:|---:|---:|---:|---:|

简单保留主拍与乐句停顿，后半段加入两段较慢弹跳。普通加入八分切分、跨手双押和两次相邻变轨的流星。困难增加局部细分、开场过门六连击、更多折返弹跳和相邻轨流星。路径段替换原有连打而非叠加全部音符，给读谱与连续跟随留空间。

长按根据中频攻击之后的稳定能量区间安排；持续时间与分析依据见 `编排依据.json`。轨道分配是手型设计，不是人声逐音音高转录。三档不是对同一张困难谱机械删音符。

## 验证

- 使用当前游戏引擎模拟普通按下/释放、流星持续跟随与弹跳每次落点：三档满分 1000000、Miss 为 0，最大 Combo 分别为 304 / 525 / 739。
- 文件重新解包后，各难度的时间、路径与音符类型保持一致；音频和封面 SHA-256 与原文件字节一致。
- 普通攻击头相对最近检测瞬态的误差中位数：简单 4.90ms、普通 5.12ms、困难 5.35ms；95 分位分别为 19.57ms、26.33ms、23.49ms。该指标来自信号分析，不能代替试听；路径的持续节点不计入攻击头误差。
- 已检查路径占用、同轨恢复、实际音频边界与分段密度。键盘占用统计在变轨边界同时计入两侧，属于保守上界。
- 未进行人工试听或真实设备试玩，不能据此声称实际手感已经验证。

主文件 `もうどくちゅうい.nlchart` 可直接导入游戏或编辑器，无需再单独导入音频。源谱、统计、对拍检查与编排依据均保留在同一目录。制作脚本从 `analysis/analysis.json` 中读取原音频路径，需要本机原文件和分析特征仍存在。
